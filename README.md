# Bushwick: Neighborhood Profile and Analysis

This project is an individual webpage highlighting Bushwick, Brooklyn, created as part of the CSCI 127 Honors Project at Hunter College (Fall 2021). While the research and analysis were completed collaboratively in a group of four, this site and its content were independently designed and coded.

**Live site:** [https://laurensgalarza.github.io/bushwick](https://laurensgalarza.github.io/bushwick)

---

## Project Overview

As part of a semester-long data project, our group analyzed Brooklyn neighborhoods using public datasets, including the NYC Open Restaurants Applications dataset. After evaluating factors such as food access and outdoor dining availability, we ranked Bushwick as a standout neighborhood.

After our group researched Bushwick using public datasets and evaluated its livability and amenities, I created this webpage to showcase key aspects of the neighborhood. It includes a static map, neighborhood descriptions, and a minimal, responsive layout.

---

## Features

- Static map displaying food-related locations in Bushwick
- Summary of neighborhood features and appeal
- Clean, hand-coded design using basic web technologies
